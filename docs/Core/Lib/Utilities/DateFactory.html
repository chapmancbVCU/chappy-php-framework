DateFactory

class DateFactory

Single point of creation for all date objects in the framework.

Every date Chappy creates should come from this class so that the application timezone, locale, and choice of mutable or immutable Carbon are applied consistently. Because "now" always comes from Carbon, Carbon::setTestNow() freezes time for everything built on this factory.
