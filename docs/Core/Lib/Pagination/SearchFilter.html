SearchFilter

class SearchFilter

Turns request input (search term, filters, sort) into find() params using whitelists only. Column names never come from user input directly, so the generated SQL is safe to concatenate; all values go through bind.

Example: $filter = SearchFilter::fromRequest($request) ->where('id != ?', [$currentUserId]) ->searchable(['fname', 'lname', 'email', 'username']) ->filterable(['acl' => ['Admin', 'Manager', '']]) ->sortable(['created_at', 'lname', 'email'], 'created_at', 'desc');

at line 62
static SearchFilter fromRequest(object $request)

Build from the request object.

Request::get() HTML-encodes every value (FormHelper::sanitize), which would turn '["Admin"]' into '["Admin"]' and "O'Brien" into "O'Brien". That encoding is for output, not queries: everything here goes through bind, and views escape on output. So decode back to the raw values before whitelist matching and searching.

SearchFilter filterJsonContains(string $column, array|null $allowed = null)

Filter rows whose JSON array column contains the selected value, e.g.

users.acl = '["Admin","test"]' matches ?acl=Admin. Portable across MySQL and SQLite: matches the JSON-encoded element, quotes included, so "Admin" will not match "SuperAdmin".
