InteractsWithTime

trait InteractsWithTime

Time travel helpers for tests.

Works in both unit tests (plain PHPUnit TestCase) and feature tests (ApplicationTestCase). Every helper sets Carbon's test "now", so it affects anything that creates dates through DateFactory or Carbon.

The real clock is restored automatically after each test.

Examples: $this->freezeTime(); $this->travelTo('2026-03-15 14:30:00'); $this->travel(5)->minutes(); $this->travel(-2)->days(); $this->travelBack();

protected mixed travelTo(DateTimeInterface|string|int $date, callable|null $callback = null)

Moves time to a specific moment.

Strings are interpreted as UTC, matching how Chappy stores dates. Integers are treated as Unix timestamps.

Without a callback, time stays at $date until travelBack() or the end of the test. With a callback, the clock returns to its previous state after the callback runs, even if it throws.

Parameters

DateTimeInterface|string|int $date

The moment to travel to.
callable|null $callback

Optional code to run at that moment.

Return Value

mixed

The callback's return value, or null without a callback.
