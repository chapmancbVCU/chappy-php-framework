Wormhole

class Wormhole

Fluent unit selector returned by InteractsWithTime::travel().

$this->travel(5)->minutes(); $this->travel(-1)->day(function() { ... });

Each method moves time relative to the current (possibly frozen) time. Without a callback the new time stays in effect and the new instance is returned. With a callback, time is moved only while the callback runs and the callback's return value is returned.
