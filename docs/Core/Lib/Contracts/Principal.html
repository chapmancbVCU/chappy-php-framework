Principal

interface Principal

Contract the auth guard/provider relies on to authenticate a model without knowing its underlying schema. A Principal exposes its identifier, its stored password, and its remember-me token through a fixed set of accessors, along with the column names backing each, so the authentication system can operate against any model that maps these concepts to storage however it chooses.
