UserProvider

interface UserProvider

Defines the contract for retrieving and validating principals from an underlying data store. A UserProvider isolates all knowledge of how users are stored and looked up, so a guard can authenticate against any backing store (a model, an external service, etc.) through a single interface. Retrieval and credential validation are kept separate: a provider can locate a principal by its credentials without verifying them, and verify a principal's credentials without re-fetching it.
