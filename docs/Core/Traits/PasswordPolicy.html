PasswordPolicy

trait PasswordPolicy

This trait contains a collection of getter functions for retrieving values regarding your password policy.

Values come from config/password.php. Applications without that file fall back to the PW_* variables in .env. Env::load() converts "true" to a boolean and numbers to integers, so values are normalized here rather than compared to strings.
