HasCasts

trait HasCasts

Read-time date casting and JSON serialization for models.

Model properties keep the raw values PDO loaded from the database (UTC strings such as "2026-03-15 14:30:00"). Nothing about loading or saving changes. Casting happens only when you ask for it:

$user->date('created_at'); // CarbonInterface in the app timezone $user->toArray(); // casts applied, dates serialized json_encode($user); // same as toArray()

Declare casts with a property or a method (the method wins on conflict):

protected array $casts = [ 'created_at' => 'datetime', 'birthday' => 'date', 'starts_at' => 'datetime:Y-m-d H:i', ];

protected function casts(): array { return ['published_at' => 'immutable_datetime']; }

Supported types:

  • datetime, immutable_datetime: a moment in time stored in UTC. Serialized as ISO 8601 UTC, e.g. 2026-03-15T14:30:00Z.
  • date, immutable_date: a calendar date with no time or timezone. Serialized as Y-m-d, e.g. 2026-03-15. Append :format to any type to choose the serialized format instead. Custom formats are rendered in the application timezone.
